# 義歯とえんげの教科書 ― 訪問ST向け学習サイト

歯科クリニックから訪問リハビリに出る言語聴覚士が、義歯の定着確認と摂食嚥下リハビリに必要な知識（嚥下の生理、歯科・義歯、評価、訓練、嚥下調整食、高次脳機能、リスク管理）を学ぶためのWeb教材です。React + TypeScript（Vite）で作られた静的サイトで、サーバーや認証は不要です。

学習用の教材です。実際の臨床では医師・歯科医師の指示と勤務先の手順に従ってください。

## 使い方

```bash
npm install        # 初回のみ
npm run dev        # 開発サーバー（http://localhost:5173）
npm run build      # 本番ビルド → dist/ に出力
npm run preview    # ビルド結果の確認（http://localhost:4173）
```

Node.js 20 以上を想定しています。

## 機能

- 章別の目次、ページ内の節ナビゲーション、前後の章への移動
- 全文検索（本文・クイズ・ケース・用語集を対象にした端末内検索）
- 読書位置・クイズの回答・ケース演習の記述を端末のブラウザ（localStorage）にだけ保存。サーバーへは送信しません
- 本文中の語句（点線下線 + ⁺）をタップすると出典カードが開き、参照元へ移動できます
- 各章末に参考文献と確認日、「用語集・参考文献」ページに全出典の一覧

## 構成

```
src/
  content/
    chapters/   各章の本文・図の参照・クイズ（ch00〜ch13）
    cases.ts    ケース演習
    books.ts    参考書紹介
    glossary.ts 用語集
    sources.ts  出典一覧（本文の {{語句|id}} から参照）
    search.ts   全文検索の索引
  figures/      章ごとのSVG図解（React コンポーネント）
  components/   レイアウト・出典カード・クイズ・本文ブロックの描画
  pages/        ホーム・章・参考書・用語集・検索（ケース演習は各部の最後の章末に埋め込み）
  lib/          ハッシュルーター・インライン記法・localStorage
```

本文中の記法: `{{表示語句|sourceId}}` で出典リンク、`==語句==` でマーカー強調。

## 静的ホスティングへの公開手順

ハッシュルーティング（`#/ch/ch01` など）を使っているため、リライト設定なしでどの静的ホスティングでも動作します。公開の実行はこのリポジトリでは行っていません。

### GitHub Pages（プロジェクトサイト）

リポジトリ名のサブパスで配信されるため、ベースパスを指定してビルドします。

```bash
BASE_PATH=/<リポジトリ名>/ npm run build
```

`dist/` の中身を `gh-pages` ブランチなどに配置し、リポジトリの Settings → Pages で公開元を指定してください。

### Cloudflare Pages / Netlify / Vercel

- ビルドコマンド: `npm run build`
- 出力ディレクトリ: `dist`
- ベースパス: ルート配信なら指定不要（既定の `/`）

### 任意のWebサーバー

`npm run build` 後の `dist/` をそのまま配置してください。
